# Task 2: Customer Retention & Churn Analysis

Data Science & Analytics Internship - Future Interns

## Task
Analyzed subscription customer data to identify churn patterns, key retention drivers, and customer lifetime trends for a subscription-based business.

## Tools Used
Python (pandas, matplotlib), Excel

## Key Insights
- Total Customers: 2,500 | Overall Churn Rate: 44.8%
- Plan tier is the strongest churn driver — Basic churns 55.5% vs Premium's 26.6%
- Acquisition channel matters too — Paid Ads churn (53.1%) nearly double Referral churn (30.3%)
- Region has little effect on churn; not a useful lever here
- Top churn reasons: Price too high (29.3%), Not using enough (17.2%), Found alternative (15.9%)
- Retention drops fastest between months 2-7 of the customer lifecycle — key intervention window
